# Service Ride

**Service Ride** adalah aplikasi booking dan penjemputan kendaraan untuk layanan servis bengkel. Project ini dikembangkan sebagai bagian dari mata kuliah **Implementasi dan Pengujian Perangkat Lunak**.

## Tentang Service Ride

Service Ride membantu pelanggan melakukan pemesanan servis kendaraan tanpa harus datang langsung ke bengkel untuk melakukan pendaftaran.

Sistem menghubungkan pelanggan dengan bengkel, mekanik, dan petugas penjemput kendaraan dalam satu layanan.

## Fitur Utama

1. Booking servis kendaraan.
2. Pemilihan bengkel.
3. Penjemputan kendaraan pelanggan.
4. Pengelolaan proses servis.
5. Informasi status servis kendaraan.
6. Pengelolaan pelanggan, mekanik, dan petugas penjemputan.
